# Quiz Application 🎯

## 📌 Project Description
This project is a desktop quiz application developed using C# and Windows Forms.

## 🧠 Technologies Used
- C#  
- Windows Forms  
- .NET Framework  

## 📊 Features
- Multiple choice questions  
- Score tracking (correct / incorrect answers)  
- Question navigation system  
- Simple and user-friendly interface  

## 🎯 Goal
To develop a basic quiz system that allows users to answer questions and track their performance.

## 🚀 Status
Completed as a C# desktop application project.
